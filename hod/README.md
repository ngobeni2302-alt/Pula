# HOD quality assurance

Implemented in `frontend/src/Dashboards.jsx`: Class performance, CAPS tracker,
Teacher logs, Interventions and Action items. The dashboard aggregates four
fictional classrooms and 148 learners. Codes 1–7 are separate from reading groups.
Support Tier means codes 1–2. Falling averages compare current and previous class
means; outliers differ from the current class mean by more than 20 WPM.

Observations, strategies, review dates, lesson completion and directives persist
on this device. Observation records are not rendered in teacher or parent views.
Demo profile selection is not authentication or a confidentiality boundary.
